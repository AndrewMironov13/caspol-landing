# Выкладка на хостинг Джино

Сайт клиента (`caspol.ru`, `parket.caspol.ru`) живёт на **виртуальном хостинге Джино**
(`srv28-h-st.jino.ru`, Apache 2.4 + PHP 7.4). Это классический хостинг: без git,
без сборки на стороне сервера — заливаем готовый `dist/` по FTPS/SFTP.

## Что нужно от клиента

1. Доступ к контрольной панели Джино **или** FTP-аккаунт:
   технический адрес (`j1234567.myjino.ru`), логин, пароль.
2. Решение по адресу: поддомен (например `sport.caspol.ru`) или корень `caspol.ru`.
   **Внимание:** в корне сейчас работающий каталог на 108 товарных страниц —
   заливка лендинга поверх снесёт его. По умолчанию считаем, что идём на поддомен.

## Разовая подготовка

1. `brew install lftp`
2. Записать адрес сайта в `.env`: `VITE_SITE_URL=https://sport.caspol.ru`
   (отсюда собираются `canonical`, `og:url`, `robots.txt`, `sitemap.xml`).
3. Доступы — в `~/.jino-caspol.env` (в репозиторий не кладём):

   ```
   JINO_HOST=j1234567.myjino.ru
   JINO_USER=...
   JINO_PASS=...
   JINO_DIR=domains/sport.caspol.ru
   ```

4. В панели Джино: создать поддомен (папка `domains/<поддомен>`), выпустить
   бесплатный SSL Let's Encrypt (Домены → домен → SSL-сертификат → «Получить»)
   и включить «Всегда использовать только HTTPS».

## Выкладка

```sh
npm run build
./deploy-jino.sh backup     # снять копию того, что лежит на сервере сейчас
./deploy-jino.sh deploy     # залить dist/, ничего не удаляя
./deploy-jino.sh deploy --prune   # то же + удалить на сервере лишнее (после backup!)
```

Файлов в сборке ~815 (150 кадров видео + мобильные + avif), объём ~24 МБ, поэтому
`lftp` льёт в 6 потоков и с `--only-newer`: повторная выкладка заливает только изменённое.

## Про `.htaccess`

Лежит в `public/.htaccess`, попадает в `dist` при сборке. Проверен на живом Apache 2.4:
HTTPS-редирект, `Cache-Control` (год для хэшированных бандлов, месяц для картинок и видео,
`no-cache` для HTML), MIME для webp/avif/mp4, gzip, закрытый листинг каталогов.

**Грабля Джино:** Apache стоит за прокси, поэтому `RewriteCond %{HTTPS} !=on` даёт
бесконечный редирект. Рабочее условие — `%{HTTP:X-Forwarded-Proto} !=https`
(так в справке Джино). Если после заливки сайт отдаёт 500 — снять `Options -Indexes`
(на некоторых тарифах `AllowOverride` урезан).
